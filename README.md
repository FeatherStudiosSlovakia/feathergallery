# Feather Gallery

A fast, clean, and completely offline Android photo & video gallery built with Kotlin and Jetpack Compose by **Feather Studios**.

## Features
- **Pinch-to-Zoom Grid:** Smoothly adjust grid density with intuitive pinch gestures.
- **Full-Screen Viewer:** Crisp zooming, horizontal swiping, and quick date scrubbing.
- **100% Offline & Private:** Zero internet permissions, no analytics, no tracking—your media stays strictly on your device.

## Permissions
- **Read Media (Images & Video):** Used exclusively to display your local photos and videos inside the app.
